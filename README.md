# CANYON RUNNER — ワイヤフレーム峡谷フライト

Three.js 製のブラウザ飛行ゲーム。USB フライトスティック（振動付き）対応 + スマホ タッチ操作対応。

## あそびかた

- **PC（スティック）**: [`flight-stick-relay/`](flight-stick-relay/) のリレーを起動し、`http://localhost:8765/` を開く（リレーが本作を配信しつつ `ws://localhost:8765/ws` で入力を中継）
- **PC（キーボード）**: ローカルサーバー経由で `index.html` を開く（`python -m http.server 8080` など）
- **スマホ / タッチ**: 同じくローカルサーバー経由で開く。画面下部の仮想スティックを操作

Three.js を CDN から取得するためインターネット接続が必要です。GitHub Pages 上にデプロイすれば iPhone の Safari からもタッチで遊べます（スティックは PC ローカルのみ）。

## 操作方法

| 入力 | 操作 |
|---|---|
| W/S | エレベータ（S=引く=機首上げ） |
| A/D | エルロン（左右旋回） |
| Q/E | ラダー（ヨー） |
| Shift/Ctrl | スロットル 増減 |
| R / P / C | リスタート / 一時停止 / カメラ切替 |
| **スティック** | 左右=エルロン 前後=エレベータ（引く=機首上げ） 手前レバー=スロットル 捻り=ラダー。トリガ=離陸・リスタート ボタン2=一時停止。クラッシュ・警告で振動 |
| **タッチ/マウス** | 画面下部の仮想スティック: 左下=スロットル(縦)・ラダー(横)／右下=操縦桿（上下=上昇・下降 左右=旋回）。遊びゼロで微細操作可・指を離しても位置保持。画面タップで離陸・リスタート |

仮想スティックは実機スティックやキーボード入力にも連動して動きます。下部スライダーでゲームスピード 0.5x〜4.0x。

## テスト

```
node test/headless-test.mjs   # 物理・地形・ギミック 77 項目
node test/input-test.mjs      # スティック WS・仮想スティック 47 項目
```

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（描画・HUD・入力統合） |
| `physics.js` | 飛行モデル（6 自由度・1/120s 固定ステップ） |
| `canyon.js` | 峡谷地形（センターライン・壁・巨岩・衝突判定） |
| `gimmicks.js` | 動く障害物・ボーナスリング・突風帯 |
| `input.js` | スティック WS クライアント + 仮想コックピット（スロットル/ラダー/操縦桿） |
| `flight-stick-relay/` | USB スティック → WebSocket 中継リレー（C11、Windows・振動 XInput） |
